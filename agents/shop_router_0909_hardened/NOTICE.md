# Shop Router 0909 Plan-10 hardening

This directory contains narrow patches around Yusuke Hayashi's public
**Shop Router 0909** agent, reproduced unchanged under
`agents/shop_router_0909/` from public notebook version 1/run 348430185.

The public implementation is licensed under Apache License 2.0. Its
`LICENSE.txt` is preserved in this directory. The original implementation
credits aurax7's Reactive Router for sale timing and shed projection. These
hardening wrappers were added locally to test a deterministic Plan-10 feeding
defect; they do not claim independent authorship of the underlying strategy.
